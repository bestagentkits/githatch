# GitHoot Product Requirements Document (PRD)

## 1. Product Summary

**GitHoot** (`githoot.com`) is a gamified developer identity and discovery layer built on top of GitHub.

Any public GitHub profile can be viewed as an interactive GitHoot guardian profile by replacing the domain:

```text
https://github.com/octocat
              ↓
https://githoot.com/octocat
```

The developer is represented by a persistent fantasy guardian companion. The guardian hatches from an AI-crafted egg through a dramatic Gacha hatching ritual, displays dynamic animations and emotions via sprite sheets (generated by Gemini Nano Banana 2), protects repositories, and serves as an expressive discovery surface driving traffic back to real developer work.

> **Core Thesis:** GitHoot is a developer attention and discovery network disguised as an addictive fantasy companion game.

---

## 2. Product Goals & MVP Scope

1. **Viral Gacha Hatch Funnel:** Provide a high-engagement, shareable hatch ritual that converts visitors into claimed guardian owners (> 20% claim rate, > 25% viral share rate).
2. **Deterministic Egg Visuals & Anti-Throttling:** 8–10 pre-generated AI egg archetypes with client-side Canvas/CSS spritesheet animations (idle, wobble, crack, hatch) requiring 0 AI API cost for anonymous views, combined with a resilient token pool and SWR caching to resist GitHub rate limits.
3. **Gemini Nano Banana 2 Pet Pipeline:** Generate high-resolution hero portraits and 4x2 multi-pose sprite matrices (idle, happy, sleepy, proud, angry, work/coding, celebrate) with automated WASM smart contour detection and green de-spill alpha masking.
4. **Early Access 100-Slot Ledger:** First 100 claimed guardians are 100% free; slot 101+ switches to a transparent cost-recovery gate ($0.99 / credit voucher) to prevent net-negative compute spend.
5. **Dynamic Animated Social Previews:** Generate dynamic animated OpenGraph assets (`/og/:username.gif`, `/og/:username.png`) and SVG README badges (`/badge/:username.svg`) with 1-click sharing to X (Twitter) and LinkedIn.
6. **Edge-First Serverless Infrastructure:** 100% hosted on Cloudflare Pages/Workers + D1 + R2 + KV for global low latency (< 150ms) and zero server maintenance cost.

## 4. Key Metrics

- **Claim Conversion Rate:** `claim_completed` / `egg_viewed` > 20%
- **Viral Share Rate:** `share_clicked` / `claim_completed` > 25%
- **Edge Latency (P95):** Route `/:username` < 150ms (Cache hit < 30ms)
- **AI Generation & Slicing Time:** < 4.5 seconds
- **Infrastructure Cost:** $0.00 (within Cloudflare Free/Pro tiers)
